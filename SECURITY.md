# Security policy

Report a suspected vulnerability privately through [GitHub's vulnerability reporting form](https://github.com/0xWhiteMage/hermes-tameru-plugin/security/advisories/new). Include the plugin revision, Hermes version and a concise description of the affected behaviour. Use sanitised or synthetic examples. Keep credentials, session data and private logs out of the report.

For issues specific to the Tameru engine, use the [engine's security reporting instructions](https://github.com/0xWhiteMage/tameru-compaction-system/security/policy).
